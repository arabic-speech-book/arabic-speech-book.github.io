# المؤتمرات والمجلات والمجتمع

حيث يُنشَر بحث الكلام — العربي والعام — ويُعرَض ويُبنى. تُميَّز المنصّات والهيئات التي تحمل عمل الكلام العربي بانتظام، إلى جانب الكبرى عالميًّا والمختبرات والشركات التي تصوغ المجال.

!!! note "هذه الصفحة تتغيّر — تحقّق قبل الاستشهاد"
    مواقع المؤتمرات تتبدّل سنويًّا، والمختبرات تُعاد هيكلتها، والشركات تظهر وتختفي. *آخر تحقّق: 2026-08-12.* للأدوات مفتوحة المصدر (SpeechBrain وESPnet وNeMo وKaldi وCoqui) انظر صفحة [الأدوات](tools.md)؛ وللمدوّنات والنماذج انظر [فهرس المصادر](resources/resource-index.md).
