# تطبيقات الكلام العربي الجديدة

يَعِد الكتاب، في ختام الفصل الثاني عشر، بمتابعة تطبيقات الكلام العربي الجديدة كلما ظهرت. وهذه هي الصفحة الوحيدة المقصود **تحديثها بعد النشر** لا مجرّد نشرها — لذا جُعِلت عمدًا أسهل صفحة في الموقع لإضافة مدخل إليها.

!!! note "مفتوحة للمداخل"
    ستُدرَج هنا الأنظمة والمدوّنات والنماذج والعروض الجديدة كلما ظهرت، الأحدث أوّلًا، كلٌّ مؤرَّخ ليرى القارئ مدى حداثته.
