# تطبيقات وطرائق الكلام الجديدة

يَعِد الكتاب، في ختام الفصل الثاني عشر، بمتابعة تطبيقات الكلام العربي الجديدة كلما ظهرت — وتفي هذه الصفحة بذلك الوعد، مع الإشارة أيضًا إلى طرائق الكلام ونماذجه وأدواته الأوسع ذات الصلة بعمل الكلام العربي. وهي الصفحة الوحيدة المقصود **تحديثها بعد النشر** لا مجرّد نشرها، لذا جُعِلت عمدًا أسهل صفحة في الموقع لإضافة مدخل إليها.

!!! note "مفتوحة للمداخل"
    ستُدرَج هنا الأنظمة والمدوّنات والنماذج والطرائق والعروض الجديدة كلما ظهرت، الأحدث أوّلًا، كلٌّ مؤرَّخ ليرى القارئ مدى حداثته.
