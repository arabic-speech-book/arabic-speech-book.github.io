# مصادر الأشكال

سكربت بايثون الذي يرسم كل شكل من **أشكال الكتاب الـ74**، حتى يمكن إعادة توليد الشكل أو تصحيحه أو تكييفه للشرائح. هذه موجودة بالفعل؛ لا تحتاج إلا إلى النشر — مجلّد لكل فصل، بأسماء ملفّات تطابق أرقام الأشكال.

!!! warning "قيد الإعداد"
    ستُنشَر سكربتات مصادر الأشكال هنا، منظَّمةً مجلّدًا لكل فصل (`figures/ch01/` و`figures/ch02/`…) بأسماء ملفّات تطابق الشكل الذي ترسمه (مثل `figure_2_4.py`). وسيعيد كلٌّ منها توليد شكله من البيانات، فيمكن تصحيحه أو إعادة تنسيقه لعرض.

**المطلوب:** سكربتات رسم الأشكال (الكود خلف الأشكال الـ74). حال مشاركتها، سأنشرها لكل فصل وأربط كلًّا برقم شكله.
