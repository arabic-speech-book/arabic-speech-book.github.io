# Chapter 14 Templates

The four fill-in templates from Chapter 14, as downloadable files rather than pages to copy from a book. A template a reader can open and type into is used; a template they have to retype is not.

!!! warning "In preparation"
    The four templates will be published here as downloadable files (editable document + PDF):

| Template | What it is for |
|----------|----------------|
| **Datasheet** | Documenting a speech dataset — provenance, composition, collection, licence |
| **Consent form** | Informed consent for voice/speech data collection |
| **Annotation guideline** | Instructing annotators for a consistent, auditable labelling task |
| **Evaluation report** | Reporting a system's results with the provenance the book asks for |
